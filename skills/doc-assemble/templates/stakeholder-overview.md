# Export: stakeholder-overview
Audience: management, sponsors · Purpose: agree scope, dates and risk
Owner: <project lead> · Sensitivity: internal

## Questions this document must answer
1. What are we building, and for whom?
2. What is in and out of this release?
3. When does each milestone land?
4. What are the biggest risks, and who owns them?

| Source | Depth | Filter |

| product/requirements.md | full | scope, release slices sections only |

| project/plan.md | key table | milestones only |
| project/risks.md | key table | top 5 by impact |

- Task-level detail

1. Summary 2. Users and goals 3. Scope 4. Milestones 5. Risks 6. Owners
